# CDTV Dream Platform

A simple MVP for a dream-sharing and emotional learning platform inspired by Channel Dreams TV.

## Features
- dream feed
- dream publishing form
- AI-like dream analysis (local rule-based prototype)
- community insights
- similar dream matching
- comment support

## Run locally

1. Install dependencies:
   npm install

2. Start the app:
   npm start

3. Open:
   http://localhost:3000

## Project idea
This MVP acts as a prototype for a product where people share dreams, emotional stories, and learn from recurring patterns across the community.
